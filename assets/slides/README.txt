Hướng dẫn xuất ảnh slide từ bài PowerPoint của Nhóm 3 (8 slide, tỉ lệ 16:9):
1. Mở file "Mô hình DNA STEM NHÓM 3.pptx" trong PowerPoint.
2. Chọn File -> Export -> Change File Type -> JPEG (.jpg) -> Export All Slides (hoặc Save As -> JPEG -> All Slides).
3. Đổi tên 8 ảnh thành:
   slide-01.jpg, slide-02.jpg, ..., slide-08.jpg
4. Đặt toàn bộ 8 ảnh vào chính thư mục này (assets/slides/).
5. Nếu bạn thêm/bớt slide, mở js/main.js và chỉnh mảng SLIDES ở đầu file.
